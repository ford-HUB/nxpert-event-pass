# NXPass — Participant Guide (skill)

Full guide: [reference.md](reference.md). Organizer counterpart: the `admin-guide` skill.

## Key model to remember

- No account is needed to attend a public event. An account adds **Browse Events**, **My Events**,
  and a photo on the welcome screen.
- Registration is **Pending** until an organizer **confirms** it; only then is the **QR pass**
  sent (email and/or Viber). **Online** events get a meeting link + calendar invite instead (no
  QR); **Hybrid** gets both.
- Each sub-event is a separate registration with its own pass.

## Status meanings

- 🟠 **Pending confirmation** — waiting for organizer; no pass/link yet (normal).
- 🟢 **Confirmed** — pass / meeting link ready.
- 🟢 **Checked in** — attended.

## Guest registration fields

Full name, ID No., "Send my pass via" (Email / Viber / Both), Email **and** Mobile (+63 9XX XXX
XXXX) both required, optional display picture, optional face check-in (needs consent tick).

## Frequent answers

- *No pass received* → passes go out after confirmation.
- *Lost pass* → **My Events → Show pass / Re-send pass email** (once confirmed).
- *Cancel* → **My Events → ⋮ → Cancel registration** unless already checked in.
- *Can't edit name / ID No. on the form* → they come from the account; change in **My Account**.
